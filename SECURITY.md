# Security Policy

## Ruang Lingkup

Kebijakan ini berlaku untuk kode dan dokumentasi dalam repository Projek-IOT.

## Melaporkan Kerentanan

Jika menemukan masalah keamanan, jangan memublikasikan detail yang dapat disalahgunakan sebelum maintainer memiliki kesempatan untuk meninjau dan memperbaikinya.

Gunakan fitur pelaporan kerentanan privat GitHub pada tab **Security** repository, jika tersedia. Jika fitur tersebut tidak tersedia, hubungi maintainer melalui kanal kontak yang tercantum pada profil GitHub.

Sertakan:
- Ringkasan masalah.
- Langkah reproduksi.
- Dampak yang mungkin terjadi.
- Bukti atau log yang tidak mengandung kredensial maupun data pribadi.

## Praktik Keamanan

- Jangan commit token, password Wi-Fi, API key, atau kredensial lain.
- Jangan menghubungkan rangkaian simulasi langsung ke perangkat tegangan berbahaya tanpa prosedur keselamatan yang sesuai.
- Pengujian perangkat keras harus dilakukan dengan catu daya dan pengawasan yang tepat.

## Status Dukungan

Repository ini merupakan proyek pembelajaran. Perbaikan keamanan ditangani sesuai kemampuan dan ketersediaan maintainer.
